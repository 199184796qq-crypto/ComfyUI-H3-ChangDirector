# H3 长序列分镜融合台（ComfyUI-H3-ContextDirector）

首先感谢熊猫怪兽AI日记的原创制作，这个版本只是在开源的情况下修改了部分功能，融入了长连续的功能来符合自己的创作习惯！再次感谢熊猫怪兽AI日记老师
这是一个面向 ComfyUI 原生 MiniMax H3 工作流的中文长视频导演台。它把"多段生成、逐段验收"的漫剧制作流程整合进**一个节点**：可视化时间轴、每段独立提示词与参考图、每段配音音频、点段预览、单段重跑，段间通过尾帧文件自动接力，最终得到一组各自独立的分段成片。

当前插件版本为 **2.21.4**。最低支持 ComfyUI **0.30.0**，推荐 **0.31.1 或更新版本**。本插件不包含模型，也没有复制 H3 的采样实现；请先确认 ComfyUI 已带有 `MiniMax H3 Reference To Video` 和 `MiniMax H3 Image To Video` 原生节点。

**云平台 Motion Context 续接：** 默认“latent 延续：本地自动续接”完全保持原有逻辑。若平台不能保存 H3 latent，可在创作界面为第 2 段及以后勾选 `MotionContext`，将来源改为“视频延续”，并在本段音频下方上传上一段成片；文件最大 **200 MB**、时长必须**小于 15 秒**、且需要包含音轨。运行时会从该视频末尾读取画面帧和音频，分别作为 Motion Context 的 `context_frames` 与 `context_audio`，不读取也不保存 latent。也可选择“上传 latent”，导入由 H3 Motion Context Save Latent 创建的 `.safetensors` 文件。

**阿里云 OSS latent 续接：** 导演台插件已内置“阿里云 OSS 配置（REST）”节点，无需额外安装 OSS 节点。将它连接到导演台左侧的 `阿里云OSS配置` 插口后，可将来源选为“Latent延续：阿里云”。配置节点的 `object_key` 是可编辑的保存目录，默认填 `H3`；程序自动补 `/`，因此填 `H3` 与 `H3/` 都会得到 `H3/clip_00001.safetensors`。`Clip_index=1` 读取上一段对象，本段生成后保存为下一编号对象。节点在内存中序列化/反序列化 safetensors，不产生本地 latent 文件。

## 主要功能

- `一体节点`：提示词编辑、参考素材、音频管理、采样、解码、保存和预览集中在单个导演台节点；模型与 VAE 仍由外部标准加载节点连接，便于复用现有工作流。
- `可视化时间轴`：每段一个格子，拖右缘调时长（5~15 秒），`+段` 无限加段，可单独停用某段。
- `每段独立配置`：提示词、种子、时长、输出帧率（8~24fps）逐段可调。
- `全局提示词`：节点顶部的全局提示词框（三个界面通用），内容会**自动拼到每一段提示词的最前面**——适合写全片统一的风格、世界观、角色外观常量，避免每段重复抄写；留空则不影响单段提示词。
- `参考图按段上传`：缩略图自动编号，写 `@图1`（或 `@image1`、`【图1】` 等）自动转换为 H3 需要的 `<Picture N>` 标签；点缩略图直接在光标处插入正确编号，不会写错。
- `尾帧接力`：每段生成后自动把最后一帧存盘，下一段勾选"续接上段尾帧"即从此画面无缝继续；取消勾选即可换场景换人物。也可用"从视频续接"上传任意 mp4 抽尾帧当起点。
- `段级音频`：每段可选 `模型音频（H3 生成）` / `参考音频驱动（对口型）`；参考音色槽 A1~A3 给不同角色配指定嗓音；支持波形可视化裁剪、起始偏移、整段静音开关；AUDIO 轨道一眼看清每段用什么声音。
- `帧锚点 Add Guide`：每段可叠加任意多个图片、音频或音画锚点；在“帧锚点 Add Guide”内填写导出片段时间，插件会自动转换为 24fps 帧号，并按时间顺序串联原生 `Add Guide for MiniMax H3`。
- `点段预览`：点选段落即可在节点内播放该段已生成的视频（带声音、可自由缩放），想重跑哪段一眼定位。
- `单段重跑`：配置哈希缓存——只改动的那一段重新生成，其他段原样保留。
- `全面板缩放`：面板顶部拖条放大整个节点；提示词、参考图、预览区各有独立拖条。
- `每段独立成片`：不强制合并，生成一段保存一段，直接拖进剪辑软件。
- `项目隔离`：每个导演台节点保存独立 `project_id`，不同工作流/不同导演台的段视频、尾帧和缓存不会互相覆盖。
- `省内存汇总`：默认只向 ComfyUI 返回最后一段尾帧和静音占位，完整音画仍保存在每段 MP4；需要下游帧/音频时可手动切到高内存完整汇总。
- `8GB稳定模式`：顶栏一键限制到最多 20 步、强制省内存预览，并在每段模型工作结束后深度卸载；建议单段约 5.2 秒（124 帧）。

## 安装

将整个文件夹放入：

```
ComfyUI/custom_nodes/ComfyUI-H3-ContextDirector
```

安装 Python 依赖（用 ComfyUI 自带的 python 执行）：

```bash
# 便携版（python_embeded）
python_embeded/python.exe -m pip install -r ComfyUI/custom_nodes/ComfyUI-H3-ContextDirector/requirements.txt

# 国内镜像加速
# -i https://pypi.tuna.tsinghua.edu.cn/simple
```

核心依赖只有 `imageio-ffmpeg`（自带 ffmpeg 二进制，写视频用）和 `opencv-python`（读视频抽帧）。torch / numpy / Pillow / aiohttp 由 ComfyUI 提供；音频读写走 ffmpeg 管道，**不需要 torchcodec、imageio 主包、本地提示词模型或额外 AI 依赖**。

然后**完全重启 ComfyUI**（关闭进程再启动，不是刷新网页）。在节点搜索中输入：

```
H3 漫剧导演台·一体节点
```

## 基本接线

导演台左侧需要连接：

- `model`：通常连接 **Ref2VA** 扩散模型；参考图、参考视频、参考音频以及软尾帧续接都使用它。纯文本/无参考素材的 8GB 单模型工作流也可以把 **FL2VA** 直接接到这里，插件会根据上游模型文件名自动选择正确 conditioning。
- `fl2va_model`（可选）：**FL2VA** 扩散模型。连接后，段间续接会自动使用 FL2VA 硬首帧；纯文本且无参考素材的段也可使用它执行 T2VA/FL2VA conditioning。
- `clip`：H3 文本编码器（Qwen3VL）。
- `vae`：H3 视频 VAE。
- `audio_vae`：H3 音频 VAE。
- `width` / `height`：输出分辨率（建议接 Resolution Selector）。
- `自动续接`：连接 `fl2va_model` 时自动使用 FL2VA 硬首帧；未连接时自动使用 Ref2VA 软参考，不再需要手动选择，也不会因为旧工作流保存了错误模式而在段间报错。
- 原来的「续接方式」仍由插件自动决定；隐藏的「每段后卸载模型」现由顶栏的「8GB稳定」按钮控制。关闭时只做常规缓存清理，开启时会在每段模型工作结束后深度卸载，稳定性更高但下一段需要重新加载模型。

导演台右侧输出：

- `images`：默认「仅预览帧」时只返回最后一个已完成段的尾帧；「单段视频输出」返回当前选中段的全部原始画面；「完整帧和音频」返回全部段统一为节点分辨率、24fps 的画面帧。
- `audio`：默认返回静音占位；「单段视频输出」返回当前选中段的原始音频；完整汇总模式返回全部段按时间顺序拼接并统一采样率/声道的音频。
- `fps`、`frame_count`：帧率与帧数；单段模式按当前段原始值输出，其余模式为 24fps 和全部已完成段总帧数。
- `latent`：当前选中段的高级自定义采样器最终 `LATENT` 输出。
- `positive`：当前选中段实际送入引导器的最终 `CONDITIONING`，可直接接入其它工作流的正向条件输入。
- `noise`：当前选中段内部“噪波随机种”生成的 `NOISE`，保留该段的种子。
- `report`：运行报告文本。

### 从 2.13.x 工作流升级

- 旧工作流中的节点名、原有输入和分段 JSON 保持兼容，打开后会自动生成并保存项目 ID。
- 如果旧工作流只使用 Ref2VA，请把它继续接到 `model`，并让 `fl2va_model` 保持未连接；插件会自动使用 Ref2VA 软参考。
- 纯文本且没有参考素材时，可以只把 FL2VA 接到 `model`，插件会自动识别并走 ImageToVideo/T2VA 路径；如果同一工作流还要使用参考图、参考音频或参考视频，则仍应把 Ref2VA 接到 `model`、FL2VA 接到 `fl2va_model`。
- 用户的 4.0 类加速工作流若使用 `TE-Speed-MiniMaxH3` 和 `ComfyUI-MiniMaxH3-TeaCache`，目标电脑也必须安装这两个外部自定义节点；它们不是本插件自带依赖。

## 分段与时间轴

1. 时间轴上每段是一个格子，标注 `段N · 起止秒数`；拖动格子右缘调整时长（0.5 秒步进，5~15 秒）。
2. 点选格子后，下方编辑区显示该段的提示词、参考图、音频与预览。
3. 直接在 ComfyUI 里运行节点：全部段按顺序生成，配置未变的段自动跳过；只勾一段的「启用」即只重跑该段。
4. 每段生成后立即写入 `output/video/h3director/<project_id>/漫剧_segN_00001_.mp4`，并在同一项目目录保存尾帧 `tail_segN_00001_.png` 供下一段接力——中途重启 ComfyUI 也不丢进度。

## 参考图与 @图N 语法

- 段 1 至少上传 1 张参考图；后续段可继续沿用（勾选续接尾帧即可），也可每段换图。
- 参考图编号规则：`Picture 1` 起按顺序编号——续接尾帧排最前，然后是本段上传图；节点内蓝条会实时显示当前编号对照。
- 提示词中写 `@图1` / `@图2`（兼容 `@image1`、`@img1`、`【图1】`），运行时自动转为 `<Picture 1>` / `<Picture 2>`。
- 更稳的方式：光标放在提示词里，直接点缩略图，自动插入正确编号。
- 换场景/换人物：取消"续接上段尾帧"，上传新图，改写提示词即可（编号前移，建议点缩略图重插）。

## 全局提示词（v2.13+）

节点顶部有一个**全局提示词**输入框（创作 / 视频 / 文本三个界面通用，隐藏在节点参数里）。它解决的问题是：很多提示词要素（全片美术风格、世界观设定、固定角色外观描述）每段都要写一遍。

- 填写后，运行节点时全局提示词会**自动拼到每一段提示词的最前面**（段提示词整体作为后半部分），再走 `@图N` 转换与 `<Picture N>` 注入——单段提示词里不用再重复这些常量。
- 留空则不拼接，完全退回"每段独立提示词"的行为。
- 典型用法：把 `Pixar-inspired 3D cartoon, soft lighting, 24fps` 这类全片统一风格写进全局框，每段只写当段动作/台词。
- **文本界面自动提取（v2.13.1+）**：全局框下方有「解析时自动提取共享提示词到全局框」勾选框（默认勾选）。勾选后，点「⚡ 解析导入」或「📂 载入文本」时，插件会扫描全部段、自动抽出**公共风格前缀 + 首段场景搭建句 + 重复出现的角色定义（取最详尽版本）**、并补 `No subtitles on screen.`，填入全局框——**仅在全局框为空时填，不覆盖你手填的内容**。省去逐段抄写常量（例如 `火龙棉花糖.txt` 9 段会自动抽出 Pixar 风格行 + 营地场景 + Puff/Blaze 角色定义）。场景取首段的完整搭建句当基准；后面段场景变了（如转入暗处）时，段内自己的场景句写在全局之后、权重更高。

## 视频界面（参考视频驱动，v2.0+）

点编辑区的「⇄ 切到视频界面」：**上方放参考视频，下方放照片**——H3 原生支持参考视频（最多 3 路，2~15 秒）：

- **白模→成片**：上方放白模/灰模渲染视频（动作+运镜），下方放人物/场景照片，生成的视频沿用白模的动作和运镜、外观全部来自照片和提示词。
- **照片人物替换视频人物**：上方放原视频，下方放新人物照片，提示词写明替换关系。
- 点视频块自动插入 `<Video N>` 标签；后端自动追加官方 `reference` 结构化声明（动作/运镜/节奏跟视频，外观跟照片），不用手写。
- 参考视频带音轨时会一并作为参考（如原视频台词节奏）；白模无音轨也正常使用。

> 提示：参考视频最长边预缩到 1280 控内存；段时长建议与参考视频时长相近。

## 文本界面（纯提示词生成 + 分镜脚本一键导入，v2.11+）

顶栏第三个页签「文本界面」：默认**不需要任何参考视频、参考图、配音、音色**——画面、人物、动作、运镜、台词、音效全部由 H3 按提示词原生生成。纯文本、无参考素材时可由 `fl2va_model` 执行 T2VA/FL2VA conditioning。与创作/视频界面数据完全独立，产出文件名也是独立的（`漫剧t_segN` / `tailt_segN`），三页互不覆盖。

核心用法是**分镜脚本解析导入**：把带时间标记的分镜文本粘进顶部脚本框，点「⚡ 解析导入」，插件自动拆段、按标记设好每段时长、把对应正文写进每段提示词。也可以点「📂 载入文本」直接选择一个本地 `.txt` 文件，载入后会自动填进脚本框并触发解析导入。支持的标记写法（每段一个标记行）：

| 写法 | 示例 | 时长来源 |
|---|---|---|
| 段标记带时长 | `段1（6.6秒）：黄昏屋顶，少年转身……` | 括号里的秒数 |
| 段标记无时长 | `段1` + 正文里写 `[0s-3s] …` 时间轴 | 正文时间轴的最大结束秒 |
| 区间标记 | `[0s-6.6s] 开场……` / `0:00-0:06 …` / `0至6秒：…` | 区间差值 |
| 时长直写 | `6.6秒 \| 独白一场……` | 竖线前的秒数 |
| 官方 Shot 格式（v2.13.5+） | `integrated_multimodal_description: [Shot 1] … [Shot 2] At 00:03.000, …` 整段直贴 | `At mm:ss.mmm` 时间戳差值（末镜沿用上一镜） |

- 官方 Shot 格式（v2.13.8 起改为「按 15s 合并段」）：H3 单次能原生生成 ≤15s，且官方格式内部就用 `[Shot N] At mm:ss` 排子镜头时间轴——所以**总时长 ≤15s 的片子不再按 Shot 拆成多段，而是合并成「一段 = 一次生成」**，段提示词保留 `[Shot N] At` 结构让 H3 自己卡内部节奏；风格句 + `overall_soundscape` / `non_diegetic_music` 也一并并入这一段，成为完整自包含的官方提示词（不依赖全局框）。**总时长 >15s** 才按贪心把连续 Shot 装进 ≤15s 的生成桶（桶内 Shot 重新相对桶起点从 0s 计时），此时风格句与音效/配乐字段进全局提示词框、由各生成桶共享。
- 混用时以「段N」类标记为准切分（正文里的 `[0s-3s]` 时间轴标签不会误拆段）。
- 时长自动吸附 H3 的 VAE 对齐档位（≈±0.3 秒误差）；超过 15 秒的段会被截到 15 秒。
- **整篇没有任何标记的长文案（v2.13.9+）：按朗读时长智能分段**——直接粘贴整篇小说/旁白稿（不写任何标记），解析时自动按标准语速（4.5 字/秒）估算每句时长，切成**每段 8~15 秒**；断点优先级 = 段落换行 > 句末标点（。！？… .!?）> 从句标点（，、：），**绝不在句中硬断**（仅无标点超长句按字数兜底切），每段都是完整的镜头/情节描述，模型好理解。3 分钟文案（约 800 字）会自动分成十几段。
- 段间默认续接上一段尾帧（跨段动作连续），可在段行取消；段行还有独立的时长/种子。
- **种子随机范围选择**（v2.13.12+）：段行种子输入框左侧新增下拉，控制 🎲 按钮行为——**当段随机**（默认，只改当前段）、**全段各自随机**（所有段各换一个新种子，画面差异大）、**全段统一随机**（所有段共用同一个新种子，角色/风格更一致）。该选择随工作流保存，创作/视频/文本三界面通用。
- 脚本框内容随工作流保存；「📚 模板库」下拉可填入官方分镜骨架当示例；「📂 载入文本」可从本地 `.txt` 直接导入并解析。
- 「⚡ 解析导入」是**整批替换**（清空现有全部段，换成脚本解析结果；有内容时需再点一次红色按钮确认）。旁边「**📥 导入到当前段**」（v2.13.11+）则**只动当前选中的那段**——把脚本解析结果原位替换/顺次插入到当前段位置，**其它段保持不变**，单击生效。适合：已有若干段，只想用一段新文案替换/插入某一格，不想整批重来。「解析时自动提取共享提示词到全局框」对它同样生效。
- 「📚 模板库」下拉（v2.13.6+）：MiniMax 官方 10 个 SKILL 模板蒸馏成 9 套骨架（官方时间线规范 + 极简产品广告 / 3D 动画短片 / 纸艺定格科普 / 纸拼贴讲解 / 品牌宣传片 / MV 歌词字幕 / 双人游戏开场 / 手绘实拍融合）。**v2.13.8 起全部改用官方 integrated_multimodal_description 格式**，每条 ≤15s、对应一次 H3 生成（内部 `[Shot N] At mm:ss` 排子镜头）。点选即把该模板的分镜骨架填进脚本框（`【】` 是占位符，换成你的内容后点「解析导入」，会自动合并成一段一次生成）。
- 时间轴段块的时长数字可点选（v2.13.7+）：点段块左下的「10.1s」弹出 VAE 对齐时长选择器，当前档高亮，点选即改；右缘拖拽调时长仍然可用。

## 参考音色槽（多角色，A1~A3）

参考图下方有**参考音色槽 A1~A3**。当前界面中的这些槽按 `reference` 关系使用：只学习声音音色和表达方式，台词内容仍由提示词指定；旧工作流中保存过的槽级配音模式字段仍由后端兼容读取。

- 点槽块自动在提示词插入 `<Audio N>`；也可手写 `@音1` / `@音2`（自动转 `<Audio N>`）。
- 提示词里把音频和人物绑定即可，如：`<Audio 1> 是 <Picture 1> 角色（S1）的音色参考`。
- H3 最多 3 路独立参考音频：本段音频的「参考驱动」占第 1 路时，音色槽编号自动从 A2 起（面板有提示）。
- 要让角色 1:1 复用一段配音并对口型，请使用本段音频的「参考音频驱动」，而不是参考音色槽。

## 环境音（重要认知）

参考音频（配音/音色槽）的条件会压制 H3 自生成环境音——提示词写"风声鸟鸣"也常常不出（实测参考音频贯穿采样全程，模型只顾模仿人声音色）。

**想要 H3 原生环境音/音效：该段不要挂任何参考音频**，纯提示词驱动（模型音频模式），
环境音写具体拟声（`wind chime rings, ding, ding`）最有效。实用策略：对话段挂音色槽保台词，空镜/转场段不挂、专门出环境音，交替排布。

## AI 提示词（v2.15+，远程 API）

提示词工具条上的 **✨ AI** 按钮只调用你主动配置的 **OpenAI-compatible Chat Completions API**，不再下载或加载本地提示词模型，不占用额外显存。

- 点 ✨ AI，可先从 API 预设选择 OpenAI、DeepSeek、OpenRouter、硅基流动或阿里云百炼，Base URL 会自动填写；中转站选择「自定义 / 中转站」。
- 模型选择提供各服务商常用模型快捷项；列表没有的新模型选择「自定义模型」，再手动填写模型 ID，不会被固定列表限制。
- 填写 `API Key` 后点「**保存设置**」。
- 点「**测试连接**」会保存当前设置并发送一次最短测试；只有点击测试或生成时才联网。
- 写一句创意或大白话分镜，选择「智能生成 / 编写模式」，点「**生成**」，结果会写回当前段提示词框。
- 选择支持图片输入的模型时，当前段参考图、续接尾帧和参考视频关键帧会随请求发送，帮助模型按素材写提示词。
- API Key 只保存在本机 `ComfyUI/user/ComfyUI-H3-ContextDirector/api_config.json`；前端接口只查询是否已配置，Key 不写入工作流、节点属性、localStorage 或日志。
- Base URL 通常填写到 `/v1`，插件会自动调用 `/chat/completions`；如果服务商给的是完整 `/chat/completions` 地址，也可以直接填写。

## 段级音频

每段音频来源二选一（v1.7.3 起；旧工作流里的"替换/混合"段会显示"旧版"选项兼容）：

| 模式 | 说明 | 口型 | 需要上传 |
|---|---|---|---|
| 模型音频（H3 生成） | 默认，H3 自己生成的声音和环境音 | 同步 | 否 |
| **参考音频驱动（v1.6+，配音推荐）** | 上传配音喂给 H3 当生成条件（`<Audio 1>`），模型听着它说台词 | **原生同步** | 是 |

> **想让角色说你的配音且口型对上，选「参考音频驱动」**。替换/混合只是把音轨贴到成片上，
> 嘴部动作仍按模型自己的节奏动，必然错位——这是原理决定的，不是 bug。
>
> 参考音频驱动有两个子模式（v1.6.1+，按 MiniMax 官方 R2V 提示词指南实现）：
>
> | 子模式 | 官方关系 | 效果 |
> |---|---|---|
> | 复刻音轨（默认） | `fully_copy` | 你的配音 1:1 用作成片音轨，画面口型对齐它（配音台词首选） |
> | 复刻音轨 + 保留 H3 环境音（v1.7+ 勾选） | `partially_copy` | 配音作对话轨 1:1 复用，H3 同时生成环境音/音效/配乐 |
> | 仅音色参考 | `reference` | 模型只学音色语气，台词按提示词重新生成（声音克隆） |
>
> 插件会按子模式自动向提示词追加官方结构化声明（`subject_definitions` / `retention_analysis` /
> `detailed_description` + `<Audio 1>` 标签）——没有这段声明模型会忽略参考音频（v1.6.0 实测踩坑）。
> 裁剪/挖洞/起始偏移在此模式同样生效（先处理音频再喂给模型），音量不适用。
> 建议配音时长与段时长接近（音长警示会提示差距）。

- 上传后显示**波形编辑器**：拖双柄裁剪（保留选中区 / 删除选中区中间挖掉），支持 `wav/mp3/m4a/ogg/flac/aac`。
- `起始偏移`：配音从段内第 X 秒开始播（自动对齐段时长，长截短静音）。
- 采样率/声道自动统一（TTS 常见的 22050Hz mono 也能直接与 32000Hz stereo 模型声混合）。
- 时间轴下方的 `AUDIO` 轨道显示每段音频状态，点"开/关"可让某段输出无声视频。
- **三种添加方式**（v1.5+）：`+音频` 按钮上传；**把音频文件直接拖到 AUDIO 轨道的段块上**；或从**音频库下拉**直接选用 input 目录里已有的音频（不用重复上传）。
- **音长警示**（v1.5+）：音频有效时长盖不住段长（尾部无声）或超出段长（被截断）时，AUDIO 段块和裁剪区会显示黄色 ⚠ 提示。
- **台词时长建议**（v1.5+）：提示词里用引号写台词（`"台词"`），编辑区顶部实时显示三档语速（慢/标准/快）的建议时长，点击即应用并自动吸附 VAE 对齐档位——写对话戏不再靠猜时长。

## 预览与逐段验收

- 点选段落，编辑区底部出现该段的视频播放器（带声音、可拖大、可新窗口放大）。
- 逐段过一遍：满意 → 下一段；不满意 → 改提示词/换参考图/调音频，只保留该段勾选「启用」再运行——只有这一段重新生成。
- 面板顶栏常显版本号；若状态栏出现红色版本警告，说明前端/后端有一边是旧代码，按提示重启或强刷即可。

## 时长、帧数与帧率

- H3 固定按 **24 帧/秒** 生成，帧数自动对齐到 `17n+5`，最终时长与填写值可能有 ≤0.5 秒差异。
- 每段可单独设置**输出帧率 8~24**：调低为抽帧（时长不变，呈逐帧动画感）。各段帧率不同时合流输出会自动统一。

## 输出分辨率

建议配合 Resolution Selector 使用：默认 `16:9 / 0.4MP / 32`（约 832×480，与 H3 原工作流一致，16GB 显存实测每 10 秒段约 8~12 分钟）。追求画质可升 `0.9MP`（约 1280×704），耗时与显存相应增加。

## 输出文件位置

每个导演台节点首次创建时会生成持久化 `project_id`。全部产物按项目隔离在：

```
ComfyUI/output/video/h3director/<project_id>/
```

创作界面示例：

```
漫剧_seg1_00001_.mp4    第 1 段成片（每段独立；创作界面）
漫剧_seg2_00001_.mp4    第 2 段成片
tail_seg1_00001_.png    第 1 段尾帧（接力用，无需管理）
漫剧_segN_00001_.json   第 N 段配置缓存（哈希跳过用，无需管理）
```

视频界面产出独立命名（`漫剧v_segN` / `tailv_segN`），文本界面同样独立（`漫剧t_segN` / `tailt_segN`），三个界面的成片与缓存互不覆盖。

### 汇总输出与内存

- `仅预览帧(推荐)`：默认。各段 MP4 保留完整画面和音频；节点 `IMAGE` 只返回最后一段尾帧，`AUDIO` 返回极短静音占位，`frame_count` 仍统计所有已完成段折算到 24fps 的总帧数。长项目不会因为把所有帧重新读回内存而爆内存。
- `单段视频输出`：只输出导演台当前选中段的完整画面和音频，保留该段原分辨率、原帧率与原始音轨；适合把一段视频接到下游节点，内存占用只与这一段有关。
- `完整帧和音频(高内存)`：供确实需要把节点输出接到下游处理时使用。插件会把不同分辨率的段 letterbox 到节点默认宽高，把不同输出帧率重采样到 24fps，并按原时长串联音频。长视频可能占用大量系统内存。

## 素材上传限制

- 参考图：常见 `jpg/png/webp`，由 ComfyUI 内置图片上传接口接收，建议单张不超过 10MB。
- 自定义音频：`wav/mp3/m4a/ogg/flac/aac`，后端限制 **100MB/文件**；内容时长建议与单段接近。
- 参考视频/续接视频：`mp4/webm/mov/mkv/avi`（续接主要使用 mp4），后端限制 **2GB/文件**；实际可上传上限还会受浏览器、反向代理和 ComfyUI 服务配置影响。
- 上传素材保存在 ComfyUI 的 `input` 目录，工作流只保存文件名，不写入媒体二进制。

## 常见问题

**改了代码/界面没变化**
前端改动：浏览器 `Ctrl+Shift+R` 强刷；后端改动：完全重启 ComfyUI 进程。面板顶栏有版本号，可对照确认。

**预览黑屏 0:00**
老版本生成的视频缺少 faststart 头，重跑该段即可（v1.3+ 生成的视频均自带）。

**换场景后画面发糊**
参考图驱动模型的正常表现：没有尾帧照画时，模型需要凭空构造新场景。建议新场景段落升到 0.9MP，并把场景图放在参考图第一位。

**提示词里出现 `<Picture N>` 英文标签**
这是 H3 识别参考图所需的官方控制标签，正文仍可全部用中文书写。

**运行时报 `Command '[...triton...tcc.exe', ...]' 失败（Windows + Python 3.13）**
报错来自 H3 模型推理链路里的 Triton 即时编译（triton-windows 用自带的 tcc 链接 CUDA / Python 库），与本插件代码无关，属于整合包环境问题，按顺序尝试：
1. 把整合包 Python 的 `libs\python313.lib`（通常在 `python_embeded\libs`，若无则从同版本官方 Python 拷贝）放到可被 tcc 找到的位置，或复制到 `python_embeded\libs` 目录下；
2. 确认已安装 CUDA Toolkit（报错命令行里引用了 `CUDA\v12.x`），并把 `CUDA\bin` 加入 PATH；
3. 在 H3 采样相关节点里把注意力实现从 Triton/SageAttention 切换为 SDPA（如节点提供该选项），绕开 Triton 编译；
4. 仍不行：把完整报错文本（不是截图）发给 H3 整合包/模型节点的作者——编译命令的最后几行才是真正的失败原因。

**面板变窄/比例不对（v1.4.1 已修复）**
低画布缩放下拖拽位移未换算导致的跳变，及个别前端版本下面板宽度脱离节点宽度的问题，已在 v1.4.1 修复：所有拖拽按画布缩放换算，并加了宽度看门狗自动校正。遇到旧版残留状态，把节点拉大一次即可恢复。
